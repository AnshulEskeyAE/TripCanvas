## 🧭 PM Lifecycle Phases (`/docs/PHASES`)

The project follows a structured evidence-based PM framework organized into phases:

| Phase | Title | Focus Area |
|---|---|---|
| **Phase 00** | [`00 - Start Here.md`](./PHASES/00%20-%20Start%20Here.md) | Framework onboarding & project scope overview |
| **Phase 01** | [`01 - Understand the Context.md`](./PHASES/01%20-%20Understand%20the%20Context.md) | Travel tech ecosystem, OTA silos, and pre-booking friction |
| **Phase 02** | [`02 - Map the Problem Space.md`](./PHASES/02%20-%20Map%20the%20Problem%20Space.md) | Multi-item speculative planning pain points |
| **Phase 03** | [`03 - Research & Discovery.md`](./PHASES/03%20-%20Research%20&%20Discovery.md) | User interviews, organizer habits, 15–25 tab chaos analysis |
| **Phase 04** | [`04 - Make Sense of the Evidence.md`](./PHASES/04%20-%20Make%20Sense%20of%20the%20Evidence.md) | Synthesis of drip pricing & spatio-temporal gap insights |
| **Phase 05** | [`05 - Define the Problem.md`](./PHASES/05%20-%20Define%20the%20Problem.md) | Core JTBD and un-solutionized problem statement |
| **Phase 06** | [`06 - Decide the Strategy.md`](./PHASES/06%20-%20Decide%20the%20Strategy.md) | Wedge strategy, competitive positioning vs Wanderlog/TripIt |
| **Phase 07** | [`07 - Explore Solutions.md`](./PHASES/07%20-%20Explore%20Solutions.md) | Dual-bundle comparison (Plan A vs B) & visual canvas concept |
| **Phase 08** | [`08 - Define the MVP.md`](./PHASES/08%20-%20Define%20the%20MVP.md) | MoSCoW scoping, feature gates, acceptance criteria |
| **Phase 09** | [`09 - Design the Experience.md`](./PHASES/09%20-%20Design%20the%20Experience.md) | Interaction states, Excalidraw integration, UI design system |
| **Phase 10** | [`10 - Build.md`](./PHASES/10%20-%20Build.md) | Implementation guidance (React 19 + Vite + Zustand + Chrome MV3) |
| **Phase 11** | [`11 - Validate.md`](./PHASES/11%20-%20Validate.md) | Usability testing, conflict engine verification, performance checks |
| **Phase 12** | [`12 - Iterate.md`](./PHASES/12%20-%20Iterate.md) | Feedback backlog and post-MVP enhancements |
| **Phase 13** | [`13 - Tell the Story.md`](./PHASES/13%20-%20Tell%20the%20Story.md) | Portfolio storytelling, executive deck synthesis, and takeaways |
