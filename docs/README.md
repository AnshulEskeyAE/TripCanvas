# PROJECT STARTER

This is a blank template to begin a new project using the Product Management Operating System.

## How to use this:
1. Copy this entire `PROJECT_STARTER` folder to your new project location (e.g., inside `01_Product_Management/Projects/`).
2. Rename the folder to your project name.
3. Open `Where Am I.md` and start at Phase 0.

**CRITICAL RULE:** Do NOT copy the reference materials (like the `ANTI_PATTERNS.md`, the actual phase guides, etc.) into your new project. Keep your project folder clean and focused on your actual work. Return to the main `PRODUCT_MANAGEMENT_OPERATING_SYSTEM` repository whenever you need guidance on what to do next.
